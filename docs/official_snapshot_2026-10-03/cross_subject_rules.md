####10. DEEP LEARNING vs MACHINE LEARNING SUBMISSIONS
1.	Teams/team members are required to design and submit as a single notebook (single submission) a EEG bio-signal processing pipeline that falls into 1 of 2 categories, Machine learning / Deep learning:
a.	Machine learning is defined as any pipeline that does not include any functions/data transformations derived from a neural network architecture, optimized using a form of back propagation through multiple connected functions, other than a single hidden layer multilayer perceptron (for XOR problems).
1.	Example of libraries that cannot be used in machine learning entries: Pytorch, Tensor flow
2.	Examples of functions that cannot be used (or neural network derivatives of) are but not limited to:
Dense, Conv1D, MaxPooling1D, RNN, Activation, Conv2D, MaxPooling2D, SimpleRNN, Conv3D, MaxPooling3D, LSTM, Masking, Conv1DTranspose, AveragePooling1D, GRU, Conv2DTranspose, AveragePooling2D, Conv3DTranspose, AveragePooling3D, Bidirectional, BatchNormalization, DepthwiseConv1D, GlobalMaxPooling1D, ConvLSTM1D, LayerNormalization 	DepthwiseConv2D, GlobalMaxPooling2D, ConvLSTM2D 
GroupNormalization, SeparableConv1D, GlobalMaxPooling3D, ConvLSTM3D, UnitNormalization, SeparableConv2D, GlobalAveragePooling1D, SpectralNormalization, MultiHeadAttention, GlobalAveragePooling2D, SpatialDropout1D, Attention, GlobalAveragePooling3D 

(functions pulled from tensor flow)		


b.	Deep learning is defined as any pipe-line that takes complete EEG data, and through multiple connected layers, optimized by forward and back propagation, produce a classification of the data into a prespecified class
1.	In contrast to machine learning algorithms, Deep learning entries are not allowed to utilize linear functions such as LDA, PCA, ICA, FIR filters, SVMs that are permitted in machine learning entries, unless specified in 10.1.B.2
2.	Deep learning entries are allowed to make use of Linear functions that adhere to one of these descriptions:
i.	Minimally filtered signal: 50Hz notch filtered (UK Mains frequency) + Broad spectrum filtering (1-100 Hz, Removes DC drift and very high frequency components) 
ii.	Expanded data transforms that maintain the time domain as an axis. Examples are: Spectrograms, Continuous Wavelet Transformation etc. These transforms must be performed in the notebook from the raw data within the compute time requirement. 
iii.	Deep learning entries are allowed to use a non-layer normalisation function before sending any data to the neural network, however this function must remain the same for each participant and not be statically customized for participant with hard coded parameters for each participant. Normalisation functions that adapt at runtime based off function of the loaded data are permitted.
iv.	Functions such as Euclidian distance, inner product, and cosign similarity are permitted as measures of similarity in final classification functions in vector databases or embedding spaces

2. Submissions that do not follow the guidelines stated above will be disqualified from receiving any of the prizes. Participants are allowed to enquire if their pipelines violate the rules stated above. Determination on what constitutes a disqualification is subject to the host’s discretion.
