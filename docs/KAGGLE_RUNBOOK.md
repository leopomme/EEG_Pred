## Execute one notebook

1. Import the selected `.ipynb` into the Kaggle account participating in that
   competition. Keep its ML/DL category in the notebook title.
2. Attach only that competition's data: Single uses
   `low-cost-motor-imagery-decoding-for-rehab`; Cross uses
   `low-cost-motor-imagery-decoding-for-rehab-cross-subject`.
3. Use CPU for ML or a CUDA GPU for DL. Start a fresh kernel and execute all
   cells with the defaults. Both DL notebooks require CUDA.
4. The loader tries the exact slug under `/kaggle/input/` and
   `/kaggle/input/competitions/`. If mounted elsewhere, set `DATA_ROOT` in the
   configuration cell to the directory containing `Training set` and that
   challenge's test folder. Do not use a common parent of both challenges.
5. Check that execution completes and saves `/kaggle/working/submission.csv`,
   `test_predictions.csv`, `metadata.csv` and `manifest.json`. DL additionally
   saves histories, checkpoints and `checkpoint_replay.json`.
6. Preserve the executed notebook version and outputs. Record its URL/version,
   environment, accelerator, runtime, CSV hash and any later score. If making
   an entry, submit the CSV generated by this actual Kaggle execution.

Local CSVs are research artifacts. Do not substitute them for the CSV from the
required Kaggle execution. Use a fresh session/output directory for another run;
the notebook refuses to overwrite completed outputs.

## Checks and practical limits

- Single fits 17 separate own-person models; Cross fits its source people.
  Neither fits on target labels/statistics.
- IDs are exactly 0–679 or 0–359; labels are lowercase `rest`/`move`.
- Manifests record sources, raw-input/output hashes and actual package versions.
- ML imports no neural framework. DL uses raw EEG and runtime normalization,
  with no classical-estimator features or narrow-band fixed filters.
- Same-L40S replay is exact, including full Within retraining. Cross-device
  identity is not assumed: CPU replay changes one historical borderline Within
  decision. Preserve Kaggle's own executed manifest and generated CSV.
- These are reproducible baselines, not selected final winning solutions.
  Cross confirmation is already used; do not tune on it or call it untouched.
- External research datasets remain deferred.
